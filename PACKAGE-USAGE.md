## 3. Package Integration & Execution

This demo project demonstrates **both** documented interaction patterns supported by `@kabeersingh/readme-buddy@0.1.0`:

### A. CLI Binary Integration

The package exposes a command-line binary `readme-buddy` (configured in its `bin` field). In this project's `package.json`, the following npm scripts are configured:

```json
"scripts": {
  "start": "node src/index.js",
  "test": "node test/taskManager.test.js",
  "generate-readme": "readme-buddy --force",
  "generate-readme:api": "node scripts/generate-readme.js",
  "preview-readme": "readme-buddy --dry-run"
}
```

Running the CLI command:
```bash
npm run generate-readme
```
or directly:
```bash
npx readme-buddy --force
```

### B. Programmatic API Integration

The package also exports a clean JavaScript API:
```javascript
const { generateReadme, buildMarkdown } = require('@kabeersingh/readme-buddy');
```

In `scripts/generate-readme.js`, this project uses the programmatic API:

```javascript
const path = require('node:path');
const { generateReadme } = require('@kabeersingh/readme-buddy');

const projectDir = path.resolve(__dirname, '..');

const result = generateReadme({
  projectDir,
  outputPath: 'README.md',
  overwrite: true,
  badges: true
});

console.log(`Generated ${result.filename} (${result.bytesWritten} bytes)`);
```

Executing the programmatic generation script:
```bash
npm run generate-readme:api
```

## 4. How `@kabeersingh/readme-buddy` Generated `README.md`

`@kabeersingh/readme-buddy` reads this project's `package.json` file as the single source of truth and constructs 8 structured sections without fabrication:

   - Parses `name` (`campus-task-manager-demo`)
   - Emits Shields.io badges for `version` (`1.0.0`), `license` (`MIT`), and Node engine (`>=18.0.0`).
2. **Project Description**:
   - Formats the exact `description` declared in `package.json`.
3. **Features Section**:
   - Analyzes `keywords` (`task-management`, `college-assignments`, `deadline-tracker`, `student-productivity`, `academic-planner`, `cli-tool`, `json-storage`, `nodejs`) and generates structured feature bullet points.
4. **Installation Section**:
   - Detects the `bin` field (`campus-tasks`) and automatically generates global install (`npm install -g campus-task-manager-demo`) and `npx campus-tasks` execution guides.
5. **Available Scripts Table**:
   - Formats a Markdown table parsing all npm scripts (`start`, `test`, `generate-readme`, `generate-readme:api`, `preview-readme`) with descriptions.
6. **Usage Guide**:
   - Detects CLI binary and programmatic main file (`src/index.js`) and outputs both CLI usage and CommonJS import usage examples.
7. **Project Information Table**:
   - Summarizes Name, Version, License, Author, Web Repository URL, Node.js requirement, and dependency counts.
8. **License**:
   - Renders the MIT license clause with author attribution.

The resulting `README.md` is preserved in the project root exactly as generated by the package.
